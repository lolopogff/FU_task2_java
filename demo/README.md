# Техническое задание на разработку веб-приложения

## Описание проекта

Разработайте веб-приложение на Java с использованием Spring, реализующее через веб-интерфейс функции добавления, просмотра, редактирования и удаления записей в одной таблице базы данных.

## Требования к функциональности

### Бэкенд (Java Spring)
- **Фреймворк**: Spring Boot
- **Архитектура**: MVC (Model-View-Controller)
- **Слой доступа к данным**: Spring Data JPA
- **База данных**: Реляционная БД с одной таблицей

### Фронтенд (Thymeleaf)
- **Шаблонизатор**: Thymeleaf
- **Верстка**: HTML + CSS
- **Стилизация**: Кастомные CSS стили
- **Компоненты интерфейса**:
    - Форма для ввода данных
    - Таблица для отображения всех записей
    - Функции редактирования для каждой записи
    - Функции удаления для каждой записи

## Функциональные требования

### CRUD операции
1. **Create** - Добавление новых записей
2. **Read** - Просмотр всех записей и отдельных записей
3. **Update** - Редактирование существующих записей
4. **Delete** - Удаление записей

### Интерфейс пользователя
- Интуитивно понятный веб-интерфейс
- Responsive дизайн (адаптивность)
- Валидация вводимых данных
- Подтверждение критических действий (удаление)
- Навигация между разделами приложения
